# Three-minute demo

1. Start the app and explain the distinction between six metadata studies and zero measured runs.
2. Search FLEX, open its source evidence, and follow the NASA section locator.
3. Clear search, select BASS and FLEX, then compare. Point out unknown materials/hardware.
4. Open Scenario, choose lunar habitat/lunar gravity and evaluate. Inspect unknown components, mismatch flags and lower/upper relevance bounds.
5. Open Library, inspect the ten-column source table, search PMMA and read a paper's findings and limits. Ask the assistant about PMMA; open the cited source and explain retrieval-only mode when no key is configured.
6. Export JSON or printable HTML. Check source URLs, the scenario and methodology version.

Do not claim identification of a safest material or quantitative fire probability.

For a supplied, documented run file: open Import, select source units, preview and confirm. Open the study to inspect observations and provenance, then compare actual run rows. Export JSON and import that bundle into another workspace: its canonical values are preserved automatically. The same workspace rejects duplicate investigation IDs. Synthetic fixtures are used only in automated tests and are explicitly labeled synthetic.
