# Three-minute demo

| Time | Show | Say |
| --- | --- | --- |
| 0:00–0:35 | Open `/present#research`, choose **Scenario explorer**, load the lunar habitat preset and evaluate. | “This scenario uses illustrative inputs. The brief checks what the imported evidence covers.” |
| 0:35–1:15 | Review the gravity check. In the Evidence Gap Map, filter to FLEX and open the run table. Follow a PSI-69 source locator. | “The dots are reported oxygen and pressure pairs from the same run. FLEX contributes liquid-droplet experiments. For this lunar scenario, the corresponding gravity evidence is missing from the filtered cohort.” |
| 1:15–1:55 | Inspect the relevance components. Switch to **Explore & compare**, select CFI-G and Saffire-II and compare their source-linked runs. | “Each row comes from a documented test. Quantities and methods constrain which values can be directly compared.” |
| 1:55–2:30 | Open **Evidence search**, search `PSI-99` and open a cited locator. | “The public snapshot retrieves curated evidence with no model key. The locator takes you back to the original record.” |
| 2:30–3:00 | Return to the scenario, open **Campaign planner**, export the proposed plan and share the research view. | “The plan records the source dataset, method, exact filters and research questions. The shared link restores the selected scenario.” |

Use **Export coverage JSON** to reproduce the chart points and checks. Use **Export scenario JSON** for relevance and coverage in one file. The full workspace at `/` adds persistent import and JSON, CSV and printable HTML investigation exports.
